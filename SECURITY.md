# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/kilo666mj/tintwire/security/advisories/new)
to share the affected version, reproduction steps, impact, and any suggested
mitigation.

Do not include credentials, private notification content, webhook URLs, push
subscription endpoints, or other third-party data unless it is essential to the
report. Redact it whenever possible.

The project will acknowledge a report, investigate it, and coordinate a fix and
disclosure timeline through the private advisory.

## Supported versions

Until the project publishes versioned releases, security fixes are made on the
default branch. Operators should follow that branch and rebuild after security
updates.
